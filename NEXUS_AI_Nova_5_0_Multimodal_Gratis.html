HTML local + Gemini API (nivel gratuito)

El historial y la memoria se guardan en este navegador. La clave API solo se mantiene en memoria mientras esta página esté abierta; no se guarda en el archivo ni en el almacenamiento local. Las preguntas y las imágenes que adjuntes se envían a Google para obtener respuestas; en el nivel gratuito, el uso de datos se rige por las condiciones de Google y puede usarse para mejorar sus productos. No envíes contraseñas, datos privados ni fotos sensibles. La clave puede ser visible para alguien que inspeccione el navegador, así que úsala solo en tu equipo y revócala si sospechas que se expuso.

No se guarda en el historial. Al cerrar o actualizar la página tendrás que introducirla otra vez. No la compartas por chat.
